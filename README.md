##  Dokumentasi & Rangkuman Kegiatan Workshop Day 1

### 1. Rangkuman Materi Utama
Pada sesi materi utama hari pertama, pemateri menyampaikan pengenalan mendalam mengenai dasar-dasar manajemen proyek teknologi dan pentingnya kolaborasi berbasis digital. Beberapa poin inti dari materi tersebut meliputi:
* **Pengenalan Ekosistem Kolaborasi:** Memahami bagaimana tim pengembang perangkat lunak bekerja secara kolektif menggunakan sistem kontrol versi terdistribusi.
* **Peran Git dan GitHub:** Mempelajari fungsi utama Git sebagai pelacak riwayat perubahan kode sumber dan GitHub sebagai pusat penyimpanan berbasis *cloud* untuk publikasi serta kerja sama tim lintas lokasi.
* **Standarisasi Penulisan Dokumentasi:** Pentingnya menyusun file `README.md` yang informatif sebagai gerbang utama bagi pembaca untuk memahami isi sebuah repository secara cepat dan akurat.

### 2. Poin-Poin Penting & Pengetahuan Baru yang Dipelajari
Selama sesi pembelajaran berlangsung, terdapat berbagai wawasan teknis baru yang berhasil diserap, di antaranya:
* **Manajemen Repository Publik:** Cara membuat, mengatur visibilitas, serta memberikan nama repository sesuai dengan aturan penamaan baku yang ditetapkan oleh panitia penyelenggara.
* **Sintaks Markdown Lanjutan:** Menguasai penggunaan heading (`#`), daftar poin (`*`), blok kode, penekanan teks (*bold/italic*), hingga penyematan tautan hypertext yang bersih dan rapi.
* **Alur Kerja Pengunggahan Berkas (*Workflow*):** Memahami langkah-langkah dasar mulai dari pembuatan *branch* utama, penyuntingan isi dokumen secara langsung (*direct edit*), hingga proses *commit changes* untuk menyimpan pembaruan file ke server GitHub.
* **Pentingnya Ketepatan Waktu & Validasi Tautan:** Menyadari bahwa aspek kedisiplinan pengumpulan tugas serta validitas tautan akses memegang porsi bobot penilaian yang sangat signifikan dalam rubrik evaluasi panitia.

### 3. Refleksi dan Pendapat Pribadi Mengenai Day 1
Pelaksanaan **Day 1 Proyek Workshop-26** ini memberikan kesan dan pengalaman yang sangat positif. Pendekatan materi yang diberikan sangat terstruktur, mulai dari tingkat pengenalan dasar hingga panduan praktis yang mudah diaplikasikan oleh peserta pemula sekalipun. 

Meskipun awalnya sempat menemui beberapa tantangan dalam memahami struktur direktori Git, penjelasan yang interaktif dari para mentor dan panitia sangat membantu dalam mengatasi kendala tersebut. Kegiatan ini tidak hanya melatih kemampuan teknis (hard skills) dalam mengoperasikan perangkat pengembangan modern, tetapi juga melatih kedisiplinan, ketelitian, serta manajemen waktu yang baik dalam merampungkan tugas sebelum tenggat waktu berakhir.
